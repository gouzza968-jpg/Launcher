# Meu Launcher (Fire TV)

Launcher para Fire TV: cartazes de filmes no topo, apps logo abaixo e menu de configurações.

## Gerar o APK
1. Crie um repositório no GitHub e envie todos os arquivos desta pasta.
2. Abra a aba **Actions**, rode **Gerar APK** (ou faça um push).
3. Baixe o artefato **MeuLauncher-apk** (arquivo app-debug.apk).

## Instalar no Fire TV
Ative **Apps de fontes desconhecidas** e instale o APK com o app Downloader.

## Cartazes reais
Em Configurações, cole uma chave gratuita da API do TMDB (themoviedb.org). Sem a chave, aparece a lista de lançamentos embutida.
